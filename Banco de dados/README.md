# Banco de Dados

Projeto desenvolvido durante a graduação em **Ciência da Computação**, com o objetivo de praticar conceitos de **Banco de Dados** e **SQL**.

O projeto envolve a criação da estrutura de um banco de dados, desde a modelagem até a implementação utilizando comandos SQL.

## 🚀 Tecnologias utilizadas

* MySQL
* SQL
* MySQL Workbench

## 📂 Estrutura do projeto

```text
Banco de dados/
│
├── Codigo.sql
└── Diagrama.mwb
```

## 🗄️ Sobre o projeto

O projeto foi desenvolvido para colocar em prática conceitos fundamentais de bancos de dados, trabalhando com a criação e organização de tabelas, relacionamentos entre entidades e definição de chaves.

A modelagem foi realizada utilizando o **MySQL Workbench**, enquanto o arquivo SQL contém os comandos utilizados para implementar o banco de dados.

## 📊 Conceitos praticados

Durante o desenvolvimento foram trabalhados conceitos como:

* Modelagem de banco de dados;
* Modelo conceitual, lógico e físico;
* Tabelas e atributos;
* Chaves primárias e estrangeiras;
* Relacionamentos entre tabelas;
* Cardinalidade;
* Integridade referencial;
* Comandos SQL.

## 🎯 Objetivo

O principal objetivo deste projeto é desenvolver uma base de conhecimento em **Banco de Dados**, entendendo como estruturar informações de forma organizada e como estabelecer relações entre diferentes entidades.
