# Machine Learning

Projeto desenvolvido para estudar e praticar conceitos de **Machine Learning e Visão Computacional** utilizando Python e o modelo **YOLO11**.

O projeto explora a detecção de objetos através de diferentes fontes, como imagens, vídeos e webcam.

## 🚀 Tecnologias utilizadas

* Python
* PyTorch
* Ultralytics
* YOLO11
* OpenCV

O projeto utiliza o modelo `YOLO11n`, uma versão leve do YOLO11 voltada para detecção de objetos.

## 🔎 O que o projeto faz

O projeto foi dividido em algumas etapas para facilitar o aprendizado:

### 1. Introdução

Primeiros testes com o modelo YOLO e sua utilização através da biblioteca Ultralytics.

### 2. Detecção em imagens

Utilização do YOLO11 para identificar objetos presentes em imagens.

### 3. Detecção em vídeos

Aplicação do modelo em vídeos, permitindo realizar a detecção de objetos em diferentes frames.

### 4. Detecção pela webcam

Utilização da câmera do computador para realizar detecção de objetos em tempo real.

## 🧠 Sobre o YOLO11

O YOLO11 é um modelo de visão computacional desenvolvido pela Ultralytics que pode ser utilizado para tarefas como detecção de objetos, classificação, segmentação e rastreamento.

Neste projeto foi utilizado o `yolo11n.pt`, versão **Nano** do modelo, escolhida por ser mais leve e adequada para testes e estudos.

## 🎯 Objetivo

O principal objetivo deste projeto é colocar em prática os conceitos iniciais de **Machine Learning, Deep Learning e Visão Computacional**, entendendo como modelos de inteligência artificial podem analisar imagens e vídeos para identificar objetos.
