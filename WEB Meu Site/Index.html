Projetos

Batalha Naval

Desenvolvimento de um jogo de Batalha Naval em Python, com tabuleiro 10x10, posicionamento de navios e sistema de ataques contra o computador. O projeto utiliza funções, estruturas de repetição, validação de entradas e lógica de programação.

Banco de Dados

Desenvolvimento de um banco de dados para um Pet Shop, estruturando informações de produtos, fornecedores, funcionários, clientes, pets, vendas e serviços. O projeto utiliza SQL, tabelas, chaves primárias e estrangeiras para organizar e relacionar os dados.

Machine Learning

Desenvolvimento de um projeto de Machine Learning em Python utilizando YOLO para detecção e identificação de objetos em imagens e vídeos. O projeto envolve processamento de dados, aplicação de modelos de inteligência artificial e análise dos resultados obtidos.

Jokenpo

Desenvolvimento de um jogo de Jokenpô em Python com três modos: Humano x Humano, Humano x Robô e Robô x Robô. O projeto conta com sistema de pontuação, escolhas aleatórias e validação de entradas, aplicando conceitos de lógica de programação.
